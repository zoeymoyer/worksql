
使用目的：生成一个使用plotly库面向多维度多场景的可复用动态可视化模块，核心功能是复刻QUICK-BI折线图柱状图组合图的所有功能（ps：如果plotly库不能实现可以选择其他能实现所有功能的python可视化库）
使用场景：将可视化脚本作为一个模块导入，读取本地excel文件，形成一个包含多个指标的可视化图表、多个维度、能进行维度筛选的综合可视化画布。
核心能力：基本原则上需要满足QUICK-BI折线图柱状图组合图的所有功能，所有模块均需要支持动态配置，能够满足不同场景的需求。
具体配置如下：
1、基础配置
  1.1 画布配置
    - 画布大小、DPI、背景颜色
    - 画布布局：支持N*M的自定义布局，默认2列多行，行数根据指标数量自动适配
  1.2 图表配置
    - 图表标题：支持自定义标题内容、字体、颜色(默认黑色)、位置(默认左上)
    - 坐标轴配置：X与Y轴单独配置，组合图是双Y轴，支持自定义坐标轴名称、字体、颜色(默认黑色)、位置(默认左侧和底部)，坐标轴范围和刻度配置
    - 图表风格：支持多种预设风格选择，满足不同场景需求
    - 图表网格线：支持显示/隐藏网格线，网格线样式配置（颜色、线型、宽度）
    - 图表轴线：支持显示/隐藏轴线，轴线样式配置（颜色、线型、宽度）
    - 图表标签：支持显示/隐藏数据标签，标签格式配置（数值、百分比、自定义等格式化），标签字体大小颜色，标签位置配置（内部、外部、中心等）
    - 图表图例：支持显示/隐藏图例，图例位置配置（上、下、左、右等），图例对齐方式配置（居左、居中、居右）
    - 图表提示框：支持显示/隐藏提示框，提示框格式配置（同图表数据标签格式化配置），提示框样式配置（背景颜色、边框颜色、字体等），默认展示所有指标维度的提示框
    - 图表颜色：支持自定义颜色配置，满足不同指标维度的颜色区分需求
2、辅助功能
  2.1 标记功能(markPoint)
    - 标记展示：支持显示/隐藏标记
    - 标记形式：支持多种标记形式选择，如横向辅助线、纵向辅助线、指定数据点
      - 横向辅助线：均值、中位数、最大值、最小值等支持输入自定义函数
      - 纵向辅助线：支持输入指定x轴位置范围
      - 指定数据点：支持输入指定数据点的x轴位置或者y轴值条件
    - 标记样式：支持自定义标记样式配置，如名称、对应标记值、颜色、大小等
  2.2 趋势线功能
    - 趋势线展示：支持显示/隐藏趋势线
    - 趋势线类型：支持多种趋势线类型选择，包括linear / log / exp / power / poly2 / poly3等，满足不同数据趋势的拟合需求
    - 趋势线公式：支持显示/隐藏趋势线公式提示，提示内容（指标+具体公式+R^2值），图例位置配置（上、下、左、右等）
3、绘图配置
  3.1 指标配置
    - 指标系列配置：图表类型配置（折线图、柱状图等，默认平滑折线图），指标数值格式化配置（千分位、百分比、自定义单位等），指标数据标签配置（显示/隐藏），指标颜色配置（支持自定义颜色），指标标记配置，指标趋势线配置
  3.2 维度配置
    - 支持单维度和多维度配置，满足不同场景需求
    - 支持维度筛选功能，支持单选和多选，满足不同分析需求
4、交互功能
  4.1 维度筛选交互
    - 支持单选和多选维度筛选，满足不同分析需求
    - 支持筛选结果动态更新图表展示，提供流畅的用户体验
5. 输出功能
  5.1 图表输出
    - 支持图表保存为本地文件，支持多种文件格式（如PNG、JPEG、PDF、HTML等）
    - 支持图表直接展示在屏幕上，满足不同使用场景需求
6.输入接口
  6.1 输入源
    - 本地文件输入：Dataframe
    - 自定义输入
  6.2 输入配置
    - 图表类型：折线图、柱状图、组合图等
    - 可视化指标：
    - 颜色图例维度：如果有值做校验，不支持组合图，仅支持单指标。目的实现不同用户类型的间夜QC趋势等等
    - 拆分维度：和颜色图例维度校验，不能相同。目的实现不同国家的不同用户类型间夜QC趋势等等
